# MobiFlight Plugin for MSFS 2024 WT21 CDUs

This is a plugin to add MobiFlight CDU support to the MSFS 2024 WT21 CDUs.

## Installation

Download `tracernz-plugin-wt21-mobiflight-cdu-vx.x.x.zip` from the [latest release](https://github.com/tracernz/wt21-mobiflight/releases), and extract to your MSFS 2024 community directory.

## Configuration

There are two settings added in a subpage linked from the WT21 SETTINGS page. The first enables/disables the plugin entirely (default enabled), and the second one enables/disables showing the FMC message from the bottom line in the scratchpad when it is otherwise empty. If that is disabled you will not see FMC messages on the remote CDU, as the Boeing and Airbus CDUs do not have enough rows.

## MobiFlight Profiles

Some MobiFlight profiles to map the WinWing CDU buttons to WT21 buttons in the sim are provided for convenience.
Download `wt21-mobiflight-cdu-profiles-vx.x.x.zip` and extract the profile(s) you need. Add them to MobiFlight either by opening
one, or add to an existing project with the plus button on the top bar.
You will then need to assign a CDU device to the orphaned device as usual.
